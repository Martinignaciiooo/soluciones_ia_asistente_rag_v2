# Bocetos de diseño EP2

Estos tres bocetos describen la preparación, consulta y estados de la interfaz Colab. Son diagramas de diseño y no capturas reales ni evidencia de inferencia. Las versiones SVG son editables y las PNG facilitan la vista en GitHub.

- 01_preparacion: subida de ZIP, secretos, prueba de Neon e indexación.
- 02_consulta: respuesta, traza, borrador, memoria y exportación.
- 03_estados: vigente, vencido, fallo, abstención y recuperación de artefactos.

Generar SVG: `python scripts/generar_bocetos.py`. La evidencia real se exporta desde el notebook; debe añadirse a docs/evidencias después de ejecutar los ensayos.
